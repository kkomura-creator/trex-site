VALUE
VALUE 01

人ファースト

テクノロジーは手段。目的は常に「人」。AIがクローンとして働くからこそ、人は創造的なことに集中できる。

VALUE 02

現場から変える

住宅業界の現場を知るからこそ、机上の空論ではなく実際に成果が出るAI活用を提案する。

VALUE 03

共に成長する

一方的なサービス提供ではなく、顧客と一緒にAI活用を学び伴走するパートナーシップ。

VALUE 04

自分らしさを尊重

AIが発信を代行し、人間のクリエイターが繊細な表現を担う。共存で自分らしさを最大限に。

VALUE 05

スピードと誠実さ

AI時代のスピード感で動きつつ、顧客との信頼関係を最も大切にする。紹介される仕事を。

VALUE 06

AI × 人間の共存

AIだけでも人間だけでもない。両方の力を掛け合わせて最高の結果を生む。それが信念。
